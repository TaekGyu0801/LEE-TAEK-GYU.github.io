# TCAD Vault Hierarchy

앞으로 CMP 연구기록은 큰 Phase 하나에서 끝내지 않고, Phase 내부를 소주제별로 나눠 관리한다.

예시:

```text
P2 — 10 µm Micro-LED Baseline
  01 Reference Selection
  02 Structure
  03 Material & Doping
  04 Physics Models
  05 Mg Incomplete Ionization
  06 Contacts
  07 Mesh
  08 Baseline Run
  90 Command Archive
```

사용자가 파일, 코드, 로그, 그림, 표 또는 결과를 보내면 ChatGPT가 내용을 보고 적절한 Phase와 소주제를 결정해 GitHub에 정리한다. 같은 소주제라도 입력값, command, 결과표, 해석, 문제점은 필요하면 별도 파일로 분리한다.
