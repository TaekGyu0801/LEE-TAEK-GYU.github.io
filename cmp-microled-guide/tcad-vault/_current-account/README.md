# Current TCAD Account Backup

현재 TCAD 계정이 종료/교체되기 전에 재현에 필요한 정보를 기록하는 곳이다.

권장 기록:
- Sentaurus release/version
- 사용한 실행 명령과 shell 환경
- 본인이 만든 프로젝트 경로와 파일 목록
- 참고한 Application Library 예제의 **이름과 설치 경로**
- 프로젝트별 재실행 순서
- 에러 해결 메모

보안/라이선스 주의: 계정 비밀번호, SSH key, 라이선스 파일, 내부 서버 민감정보, 재배포 권한 없는 Synopsys 원본 매뉴얼/라이브러리는 공개 저장소에 올리지 않는다.
